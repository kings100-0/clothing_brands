KINGS BRANDS — Multi-page ecommerce front-end starter

PAGES (separate HTML files)
- index.html — Home page and animated hero slideshow
- products.html — Product catalogue with 50 starter products, filters and search
- cart.html — Shopping cart
- checkout.html — Checkout form
- orders.html — Order history and tracking
- support.html — Feedback and support
- admin.html — Admin workspace

SHARED ASSETS
- styles.css — shared responsive styling
- app.js — shared product/cart/order/admin logic and browser localStorage

RUN
Extract the ZIP and open index.html using VS Code Live Server or another local web server. All pages share the same stylesheet and JavaScript file. The Google Fonts and Unsplash photography require internet access.

IMPORTANT
This is a front-end prototype. The admin password is visible in app.js and is not secure authentication. Data is stored only in the current browser's localStorage. Checkout does not process real payments or send orders to a server. Before going live, add a backend/database, secure admin login, Paystack or Flutterwave integration, server-side order management, stock control and customer notifications.
